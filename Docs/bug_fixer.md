# Bug Fixer
## Bug Fixer Instrucciones
- Este documento entrega las instrucciones para el rastreo de bugs y problemas en la aplicación Doc-Muse que necesitan resolución. 
- Todos los problemas activos se encuentran documentados en [bug_fixer.md](../Docs/bug_fixer.md)
- Cada vez que quieras reparar o corregir un problema, revisa siempre antes este archivo en búsca de la documentación actualizada del problema. Si el problema no está documentado, documenta el problema, su descripción, los pasos para su corrección y lo que se debe revisar para determinar que está "Done".
- Cada vez que necesites crear un nuevo archivo revisa antes en la estructura del repositorio y determina el lugar donde debe ser desarrollada, e identifica si ya exiten archivos que cumplan el propósito. Nunca dupliques archivos, carpetas ni código, si la estructura cambia, acualizala en este documento al finalizar.
- Al finalizar cualquier corrección, actualiza la vitácora del problema en [bug_Vitacora.md](../Docs/bug_vitacora.md) el cuál siempre debe mantenerse con información actualizada.
- Mantén este fichero liviano y con objetivo de ayudar a agentes IA a resolver problemas. No es necesario que sea comprensible por humnanos. 
- Cuando determines que existe un problema describelo de la forma más efectiva y eficiente posible.
